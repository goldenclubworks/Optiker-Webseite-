# DESIGN_SYSTEM — OPTIK SCHORCHT (Premium, zeitlos)

## Typografie
- **Schriftfamilien:**
  - Headline: `"Times New Roman", "Georgia", serif` (ruhig, seriös)
  - Body/UI: `"Helvetica Neue", "Arial", system-ui, sans-serif`
- **Skala (Desktop / Mobile):**
  - H1: 48/34
  - H2: 32/26
  - H3: 22/20
  - Body: 18/16
  - Small: 14/14
- **Zeilenhöhe:** 1.4–1.7 (Body), 1.2–1.3 (Headings)

## Spacing-System
- Basiseinheit: 8px
- Section-Spacing: 64–96px
- Card-Spacing: 24–32px
- Grid-Gap: 24px

## Farbpalette
- **Deep Graphite:** #1F1F1F (Primärtext)
- **Warm Sand:** #F4F1EC (Hintergrund)
- **Ivory:** #FFFDF9 (Sektionen/Hintergründe)
- **Olive Accent:** #6A7D5C (CTA)
- **Muted Gold:** #B79C6E (Sekundär-Akzente)
- **Border/Line:** #E1D9CC

## Komponenten
- **Buttons:**
  - Primary: Olive Accent, weißer Text, weiche Kanten (8px)
  - Secondary: transparenter Hintergrund, Olive Border
- **Card:**
  - Weißer Hintergrund, feine Border, Schatten sehr subtil
- **Section:**
  - Full-width, max-width 1100px, zentriert, großzügiger Top/Bottom Space
- **Grid:**
  - 2–3 Spalten Desktop, 1 Spalte Mobile

## Accessibility
- Mindestkontrast für Text (WCAG AA)
- Sichtbare Fokus-Styles (outline + offset)
- Button/Link Hit-Targets ≥ 44px Höhe
- Semantische Struktur (H1/H2/H3)
